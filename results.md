## 1. Approach

The experiment uses all 800 labeled PS-Q2 rows and all 50 numeric features.
Five-fold stratified cross-validation is performed on the labeled training file
only. Standardization and PCA are fitted independently inside each training
fold, preventing validation-fold leakage. The quantum branch reduces the 50
standardized inputs to six fold-fitted PCA coordinates; the classical RBF-SVM
baseline keeps all 50 standardized features. Both branches use the same rows
and folds.

The six PCA coordinates drive a shallow six-qubit weak-ZZ ring with fixed
`theta_scale = 1.2` and `beta = 0.1`. The ring is mapped to Processor D's
physical cycle `4-0-2-5-1-3-4`. The ideal kernel is the squared pure-state
overlap. The noisy kernel is the normalized Hilbert–Schmidt overlap
`Tr(rho_i rho_j) / sqrt(Tr(rho_i^2) Tr(rho_j^2))` of density matrices simulated
under the unmodified organizer noise model. The feature map is fixed rather
than variational: it has **0 trainable quantum parameters** and six
data-encoding inputs per sample.

After model selection, the selected preprocessing/model is refitted on all 800
labeled rows and writes one `sample_id,label` prediction for each of the 200
unlabeled test rows. Test labels are neither supplied nor used.

## 2. PS-Q2 generated results

The authoritative full-precision result record is

| Model | Selected settings | Five held-out balanced-accuracy scores | Mean ± sample SD | Descriptive 95% *t* interval |
|---|---|---|---:|---:|
| Quantum kernel, ideal | `C=1` | 0.7072, 0.7061, 0.7631, 0.7186, 0.7501 | **0.7290 ± 0.0261** | 0.6966–0.7614 |
| Quantum kernel, QFF2026-v2 noisy | `C=1` | 0.6943, 0.7061, 0.7631, 0.7256, 0.7441 | **0.7266 ± 0.0278** | 0.6921–0.7612 |

Noise lowers mean balanced accuracy by only **0.0024** in this simulation. The
noisy quantum and classical means differ by **0.0007**, while their descriptive
intervals overlap heavily. The honest conclusion is parity on these folds, not
evidence of quantum advantage. The official hidden test alone determines the
submission metric.

The ideal-to-noisy training-kernel mean absolute difference is **0.0733**, while
mean centered kernel alignment remains **0.9976**. Mean off-diagonal standard
deviation contracts from **0.1875** to **0.1789**, showing modest noise-induced
concentration without destroying the learned geometry.

### Required fold and confidence reporting

For each selected model, the final result summary reports:

1. all five held-out-fold balanced-accuracy scores;
2. their arithmetic mean;
3. their sample standard deviation; and
4. the descriptive 95% Student-*t* interval
   `mean ± t_(0.975, 4) * sample_std / sqrt(5)`.

The five values are retained in the JSON rather than reporting only a mean.
They are training-only model-selection estimates from related folds, not five
independent experiments and not a confidence interval for hidden test-set
accuracy. The official test labels remain unavailable, so no test balanced
accuracy is claimed.

## 3. Task A — Bell-state fidelity

The official `task_a_bell()` benchmark is run with 8,192 shots per measurement
basis and saved to `results/phase2/task_a_results.json`. It uses
`F = (1 + <XX> - <YY> + <ZZ>) / 4`, with correlation and fidelity standard
errors calculated by the kit.

| Condition | `<XX> ± SE` | `<YY> ± SE` | `<ZZ> ± SE` | Fidelity `± SE` |
|---|---:|---:|---:|---:|
| Ideal | 1.0000 ± 0.0000 | -1.0000 ± 0.0000 | 1.0000 ± 0.0000 | **1.0000 ± 0.0000** |
| Noisy, QFF2026-v2 | 0.8191 ± 0.0063 | -0.8279 ± 0.0062 | 0.8735 ± 0.0054 | **0.8801 ± 0.0026** |

Depolarizing gate noise and readout error reduce the measured correlations and
therefore the Bell fidelity. These are fixed, seeded simulator estimates under
the organizer's benchmark conditions, not hardware measurements.

## 4. Task B — Processor D QFT-3

Processor D has six qubits. Its coupling graph contains the cycle
`4-0-2-5-1-3-4` used by the PS-Q2 feature map and additional K4 chords among
qubits 0–3. Every connection is listed in both directions because the official
benchmark treats each `[control, target]` pair as directed. Bidirectional links
avoid direction-reversal synthesis and its additional one-qubit depth and
noise.

| Official QFT-3 measurement | Value |
|---|---:|
| Circuit depth before transpilation | 6 |
| Circuit depth after transpilation | 18 |
| Two-qubit gate count | 9 |
| SWAP overhead | 0 |
| Ideal fidelity | 1.000000 |
| Noisy fidelity, QFF2026-v2 | 0.668377 |

The benchmark output is preserved in
`results/phase2/processor_d_benchmark.txt`. The notebook parses the official
command's emitted JSON and compares every field with
`processor_d_config.json`; it raises an error on any difference even though the
official command itself only prints a warning for stale embedded values.

The zero SWAP overhead shows that this QFT-3 instance can be placed without
extra routing SWAPs. It does not imply a noiseless implementation: native gates
still accumulate the fixed 1% single-qubit and 5% two-qubit depolarizing noise,
which is reflected in noisy fidelity. Task B has no measurement, so its 2%
readout model does not enter this fidelity.

### Topology tradeoff for PS-Q2

Following the six-edge physical cycle gives every weak-ZZ ring interaction a
direct link and avoids routing SWAPs for that mapped layer. Relative to a
six-qubit all-to-all feature map (15 pair interactions), the sparse ring lowers
two-qubit work, compiled depth pressure, and accumulated noise. The tradeoff is
reduced direct long-range interaction and potentially lower expressivity. The
K4 chords remain available to the QFT benchmark and other workloads, but the
classifier's ring does not claim that every available edge must be used.

## 5. Limitations and honest assessment

- Five-fold balanced accuracy is a training-only model-selection estimate, not
  a hidden-test result. Fold confidence intervals are descriptive and do not
  make the folds independent.
- PCA can discard predictive information, while retaining all 50 features in
  the RBF baseline can include predominantly noisy dimensions. This difference
  is part of the documented model comparison.
- The noisy density-matrix kernel uses gate noise but no measurement. Readout
  error therefore does not enter PS-Q2's kernel, although Task A includes its
  official measurement procedure.
- A topology with zero QFT routing SWAPs does not establish quantum
  classification advantage. Any ideal/noisy/RBF ranking must be stated from
  the final generated fold metrics without overclaiming.
- Simulator wall time and memory use depend on the execution machine.

## 6. Reproduction and validation

From a clean clone on Linux/WSL:

```bash
python3 -m venv .venv && . .venv/bin/activate && python -m pip install -r qml-requirements.txt && python -m nbconvert --to notebook --execute solution.ipynb --inplace --ExecutePreprocessor.timeout=-1
```

The notebook checks every direct package pin before importing the benchmark,
runs and saves official Tasks A and B, calls `run_experiment()`, and invokes the
official command below after predictions are written:

```bash
python tools/validate_predictions.py q2 predictions_q2.csv
```

Any package mismatch, Task B result mismatch, model failure, or validator error
aborts execution. No application-control exception or unofficial structural
check is required.
