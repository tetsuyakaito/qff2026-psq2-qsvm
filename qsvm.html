One training set. Two model families.

Preprocessing is refit inside each training fold. After model selection, the chosen noisy quantum model is refit on all 800 labeled rows to produce the required test predictions.

01

Use the labeled data

All 800 training rows and all 50 features enter model selection. The official test file contributes 200 feature rows only.

02

Fit within each fold

Standardization and six-component PCA are fitted on each fold's training partition. The RBF-SVM uses the same folds and all 50 standardized features.

03

Encode six components

A fixed six-qubit weak-ZZ ring uses θ = 1.2 × tanh(component / 2) and β = 0.1. It has zero trainable quantum parameters.

04

Select on balanced accuracy

Five shuffled stratified folds, seed 42. Quantum SVC C ∈ {0.1, 1, 10}; RBF-SVM C ∈ {0.1, 1, 10} and gamma ∈ {0.01, 0.02, 0.05}.

Kernel definitions: ideal uses squared state overlap. The noisy kernel uses normalized Hilbert–Schmidt overlap, Tr(ρᵢρⱼ) / √[Tr(ρᵢ²)Tr(ρⱼ²)], under the unmodified QFF2026-v2 gate-noise model. The kernel simulation has no measurement step, so readout noise does not enter PS-Q2.

A few terms

Balanced accuracy
Average recall across the two classes. The official PS-Q2 metric.
Cross-validation (CV)
Repeated train/validation splits within the labeled training set. These scores estimate model selection performance, not hidden-test performance.
Ideal / noisy kernel
Pairwise state similarities from exact statevectors or QFF2026-v2 density matrices.
RBF-SVM baseline
A classical support vector machine using all 50 standardized input features.

Reported values are generated artifacts from the QFF2026 QML Track v3 Phase 2 submission. No hidden-test metric or quantum-advantage claim is made.
