One training set. Two model families.

Preprocessing is refit inside each training fold. After model selection, the chosen noisy quantum model is refit on all 800 labeled rows to produce the required test predictions.

01

Use the labeled data

All 800 training rows and all 50 features enter model selection. The official test file contributes 200 feature rows only.

02

Fit within each fold

Standardization and six-component PCA are fitted on each fold's training partition. The RBF-SVM uses the same folds and all 50 standardized features.

03

Encode six components

A fixed six-qubit weak-ZZ ring uses θ = 1.2 × tanh(component / 2) and β = 0.1. It has zero trainable quantum parameters.

04

Select on balanced accuracy

Five shuffled stratified folds, seed 42. Quantum SVC C ∈ {0.1, 1, 10}; RBF-SVM C ∈ {0.1, 1, 10} and gamma ∈ {0.01, 0.02, 0.05}.

Kernel definitions: ideal uses squared state overlap. The noisy kernel uses normalized Hilbert–Schmidt overlap, Tr(ρᵢρⱼ) / √[Tr(ρᵢ²)Tr(ρⱼ²)], under the unmodified QFF2026-v2 gate-noise model. The kernel simulation has no measurement step, so readout noise does not enter PS-Q2.

Simulated backend · declared coupling map

Processor D is a custom six-qubit simulated target. Qubits 0–3 form a fully connected K4 core; qubit 4 links to 0 and 3, and qubit 5 links to 1 and 2. PS-Q2 maps its six-edge weak-ZZ ring onto direct links 4–0–2–5–1–3–4. This uses the configured QFF2026-v2 noise model; it does not run on physical hardware.

The Bell state: a compact test of entanglement.

Task A · official benchmark

A Hadamard gate followed by CX prepares the Bell pair |Φ⁺⟩ = (|00⟩ + |11⟩) / √2. Task A measures XX, YY, and ZZ correlations, then combines them into fidelity. These are seeded QFF2026-v2 simulator results, not hardware measurements.

Prepare the Bell pair

The CX control is q0 and its target is q1. Ideally, measuring both in Z gives 00 or 11 with equal probability. The official fidelity also checks X- and Y-basis correlations.

Entanglement: the Bell pair is a joint state that cannot be separated into independent states for q0 and q1.

Terms used in this run

Balanced accuracy
Average recall across the two classes. The official PS-Q2 metric.
Cross-validation (CV)
Repeated train/validation splits within the labeled training set. These scores estimate model selection performance, not hidden-test performance.
Quantum kernel / QSVM
A quantum circuit computes pairwise sample similarities; a classical SVM fits and predicts from that kernel.
Ideal / noisy kernel
Ideal uses exact statevector overlaps. Noisy uses normalized density-matrix overlaps under QFF2026-v2.
Weak-ZZ ring
The fixed six-qubit feature map used by PS-Q2. Its six data-dependent ZZ interactions follow Processor D's highlighted cycle.
RBF-SVM baseline
A classical support vector machine using all 50 standardized input features.
Bell state and entanglement
|Φ⁺⟩ is a two-qubit entangled state. Its XX, YY, and ZZ correlations are combined into the official Task A fidelity.
CX and SWAP
CX is a two-qubit controlled-X gate. A routing SWAP moves qubit states and is commonly decomposed into three CX gates.
QFF2026-v2
The organizer's fixed noise model. Readout noise applies to measured tasks such as Task A; it does not enter the unmeasured PS-Q2 kernel.
Processor D
A configured six-qubit simulated coupling graph. Its topology is transpiled and evaluated with the organizer's noise model.

Reported values are generated artifacts from the QFF2026 QML Track v3 Phase 2 submission. No hidden-test metric or quantum-advantage claim is made.
